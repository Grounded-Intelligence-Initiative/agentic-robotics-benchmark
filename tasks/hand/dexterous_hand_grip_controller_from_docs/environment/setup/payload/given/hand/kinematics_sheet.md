# The hand: kinematics sheet

The hand is a four-digit robot hand: three fingers and a thumb. 13 servo actuators VKR-4LBA drive 13
joints directly. In each finger the last joint (dip) is not driven: a crossed four-bar with a rocker couples it to the
finger's pip axis (section 3). Each digit's last link carries a tactile module (section 4).

All values below are in the hand frame H (x across the palm, y from the wrist towards the fingertips, z from the
palmar side (-) to the back of the hand (+)) with every joint at 0 deg, in metres, kilograms and degrees. The palm is
the fixed root. The links' meshes are in `meshes/` (one binary STL per link, `meshes/README.md`).

## 3. The four-bar of each finger

The four bars of a finger's loop, each from pin to pin: on `<finger>_pitch` from the pip axis to the rocker's base pin
(`pitch`), on `<finger>_pip` from the pip axis to the dip axis (`pip`), on `<finger>_dip` from the dip axis to the
rocker's tip pin (`dip`), and the rocker itself (`rocker`). The law gives the finger's dip angle for each pip
angle; between the rows it is linear.
