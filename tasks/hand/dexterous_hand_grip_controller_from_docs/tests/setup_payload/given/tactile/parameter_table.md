# Tactile modules: the vendor's parameter table

The tactile modules' vendor publishes one parameter table for its module family (the fingertip tactile module
ZCP-F561 and the thumb tactile module ZCP-DG1Z belong to it). The table below is a transcription of
the vendor's table, translated into English; the figures are the vendor's.

| parameter | value |
|---|---|
| Measurement output (optional) | three-dimensional array of distributed force, three-dimensional resultant force, three-dimensional moment (optional) |
| Number of tactile signals | up to 717 channels |
| Measurement range | normal 0 - 25 N, tangential ± 10 N |
| Operating temperature | 0 ~ 50 °C |
| Overload temperature | -20 ~ 120 °C |
| Flame-retardant grade | V-0 (the highest flame-retardant grade of the UL94 standard) * |
| Service life | more than 10 million measurements * |
| Measurement sampling frequency | 1000000 Hz |
| Maximum output frequency | 1000 Hz * |
| Minimum detectable force | 0.01 N * |
| Spatial resolution | 0.1 mm * |
| Safe overload | 200% |
| Impact overload | 300% |
| Repeatability | < 0.5%FS |
| Water and dust protection | IP68 |
| Stray magnetic field immunity | chip-level magnetic immunity |
| Operating voltage | 3 ~ 5 V supported |
| Surface coverage | front face and curved side edges fully covered |
| Dynamic temperature compensation | provided |
| Torque sensing | rotation about any point supported |

\* Data from the vendor's laboratory. Parameters marked with \* are customised to order.

The vendor's table states no calibration of a module mounted on this hand (`tactile_interface.md`, section 4).
