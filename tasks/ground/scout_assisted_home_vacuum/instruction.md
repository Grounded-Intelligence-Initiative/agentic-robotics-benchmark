# Scout-assisted vacuum in an unfamiliar home

Write a controller for a ground cleaning robot and a faster indoor survey drone. A customer's English request names two rooms to vacuum and the mat for a lightweight carton. Clean the two marked spills in each requested room and the hall spill under the carton. Park the carton on the named mat and return the vacuum to its dock. There is no prescribed order. The layout, furniture, mess, goal and starting side vary. The apartment stays fixed during a run.

Submit an executable `/home/user/submission/run.sh` and any helpers there. It must print `READY` and flush stdout, then process one JSON object per line. Reply to `{"type":"reset"}` and `{"type":"close"}` with `{"ok":true}`; forget all episode state on reset. For `{"type":"act","t":0,"obs":{...}}` return e.g. `{"action":["E","N",2,true]}`. Log only to stderr. Python, Pillow, NumPy and MuJoCo are installed in `/opt/venv`. You may coordinate both robots in one program and build your own map.

**What you get:** `instruction`; `ground` and `air` (base64 PNG, RGB, 84 by 84); `moved` (the counts of cell moves actually completed on each robot's previous command, initially zero); `left` (shared ticks remaining); and `flight` (drone ticks remaining). The two robots start together at the dock. There are no coordinates, room boundaries, top-down house map or online scores on the wire.

The cameras are modeled as stabilized, north-up, rectified downward views, centered on the respective robot. The vacuum sees a 3 by 3 tile patch; the scout sees 7 by 7. North is image up. Black is unobserved. Walls occlude both views; furniture occludes the vacuum. A robot's own body is masked. Calibration swatches (sRGB hex): hall B6AE9E, oak C99762, sage 87AF90, slate 849DB5, rose C095AA; walls 656577, furniture 285750, dirt 684127, carton E4AC29, mats CB4D5D (red) / 397ECB (blue), dock 24A99C. Objects can hide dirt and mats. This benchmark uses grid-aligned motion primitives in a furnished 3D model; it does not test flight stabilization.

**Actions:** `[vacuum_direction, scout_direction, scout_stride, suction_on]`. Directions are `N/E/S/W/stay`, stride is 0, 1 or 2, and suction is a JSON boolean. Each request advances **one shared tick**. The ground robot attempts one tile move. Walking into the carton pushes it one tile in the same direction only if the space beyond is clear. It cannot pull. While suction is on, the brush removes dirt at the vacuum's final tile, even if stationary. The aircraft may pass above the carton and furniture, but not through walls. Its first 36 ticks of flight elapse whether it moves or hovers; afterward `air` is null. Both actions execute concurrently; the standard deadline is 150 ticks. A blocked move still uses the tick.

**Scoring:** For each requested room and the hall, measure the fraction of its initial dirt physically removed. Each episode awards 45% for the mean of those three fractions, 25% for the correct final carton placement, and 30% only if all cleaning and parking goals are met and the vacuum returns to dock. Full completion ends the episode. An aborted episode receives zero. The grader uses its own simulator across private layouts; a written route, map or self-reported result is not a submission.
