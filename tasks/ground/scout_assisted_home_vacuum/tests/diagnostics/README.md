# Reproducing the scout ablation

Use Python 3.12, the packages in `environment/requirements.txt`, and Mesa's libOSMesa. Run from the task directory with `CUDA_VISIBLE_DEVICES="" LP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1`. The simulator uses CPU rendering. These are developer diagnostics, not secret grading seeds.

```bash
python tests/diagnostics/test_task.py -v
python tests/diagnostics/gallery.py --seed 804 --preview household.png
python tests/diagnostics/pilot.py --seeds $(seq 5201 5206) --ticks 200 > paired200.jsonl
python tests/diagnostics/pilot.py --seeds 11 12 13 24 37 58 --modes adaptive > reference.jsonl
```

The ground planner is the same in all modes. **Solo** disables the scout and uses a precommitted guess at the unknown work order. **Informed-solo** disables the scout but supplies the correct four swatches as a diagnostic intervention. Comparing that control to scouting separates the benefit of the map from access to the order. **Fixed** and **adaptive** both fly down the hall to read the card; fixed then flies a row-ordered survey using only the aircraft's mapped cells, while adaptive uses the shared map and unfinished work to choose where to survey. Both have the same 36 flight ticks. Only the explicitly named informed-solo control gets privileged information; the scored reference sees exactly the normal images and motion feedback. Pair runs by seed and scene.

The shipped public camera examples are regenerated by adding
`--examples environment/setup/payload/cameras.jsonl --dispatch environment/setup/payload/dispatch-example.png` to the gallery command.
The whole-house and interior images are **reviewer views**; the two 84-pixel RGB frames
are the real, concurrent robot inputs. Finishes are credited in
[`../interior_materials/`](../interior_materials/CREDITS.md) and furnishings in
[`../furnishings/`](../furnishings/CREDITS.md); all assets are local.

The carton must be staged on one of two indoor mats and returned to one of two hall mats. The panel and both camera mountings are independently randomized. The generator searches for reversible push routes to both indoor mats. The 100-seed test executes the two requested deliveries. A matched-home test changes only the card: the prompt and ground image stay identical while the true order and scout image change. Only the two requested rooms may be vacuumed; the identical-looking patches elsewhere are treatment powder.

The generator rotates and changes the connections of four furnished rooms, including
through-suites, alcoves, furniture footprints and protected runners. Ground motion and
flight are discretized. The official task is not a continuous-dynamics or real-house
deployment test. A six-seed controller comparison is not evidence of frontier-model difficulty.
