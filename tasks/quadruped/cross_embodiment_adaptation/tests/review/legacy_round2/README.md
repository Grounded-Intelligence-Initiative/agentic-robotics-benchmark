# Historical Maintainer Round 2 (v3)

This is a byte-preserved archive from upstream PR37 commit 9d8cc14. Its floor
localization world, complete image-only reference, oracle, ablations, source,
hidden-suite selection and measured anchor belong to maintainer round 2, which
called its protocol v3. They are NOT measurements of the active v4 redesign.

Original paths are retained below this directory. The sole filename mapping is
task.toml -> maintainer-task.toml to avoid discovering an extra benchmark task.
The latest hidden/sites.json and hidden/candidates.json are also the active v4
suite: v4 retains them byte-for-byte, but regenerates geometry by the documented
outcome-independent payload-world policy. No historical score is inherited.

V4 deliberately replaces round 2's carrier floor-only localization/odometer
mechanics with native force-driven elongated-payload transfer, swept-volume
turning constraints and oriented docking, observed through low onboard cameras.
The former reference is archived intact rather than presented as a broken v4
baseline. Current security authorization, larger budgets and isolation remain.
