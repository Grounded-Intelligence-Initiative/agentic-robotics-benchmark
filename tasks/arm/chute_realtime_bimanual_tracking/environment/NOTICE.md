# Third-party material used by this task

Large third-party packages and assets are fetched at build time. The small compatibility
patch and Kit experience configuration are included in this folder.

| Material | Source | Licence |
|---|---|---|
| OmniGibson (simulation framework) | github.com/StanfordVL/BEHAVIOR-1K, commit bd049de, with `environment/omnigibson-isaac61.patch` | MIT |
| Galaxea R1Pro robot model | `omnigibson-robot-assets-3.8.2.zip` from Hugging Face `behavior-1k/zipped-datasets` at revision `9f0d57d465726976ed98138d3f8b8ca3e2186775` | MIT |
| YCB objects (20 task parts, 2 bystanders in a full shift) and Simple_Room backdrop | NVIDIA's public Isaac asset bucket (`Isaac/Props/YCB/Axis_Aligned`, `Isaac/Environments/Simple_Room`), the source the merged task `object_finding_and_organizing_on_messy_desk` uses | NVIDIA Omniverse asset licence |
| Isaac Sim 6.1 | pypi.nvidia.com | NVIDIA Isaac Sim licence (EULA accepted in the image) |

No BEHAVIOR-1K scene or object data is used: its licence forbids redistribution. The track, the tote, the side table
and the slat conveyor are generated by `tests/props.py`; the collision parts of the YCB items are computed at build
time by `environment/build_items.py` (CoACD).

Build integrity: `fetch_robot_assets.py` verifies the robot archive SHA256 before extraction.
`nvidia-assets.json` freezes the 277 required NVIDIA files, their sizes and SHA256 hashes,
measured from the original exact-Docker download layer. The mirror verifies both downloads
and existing cached files. `usd-core==26.11` is fixed to the version observed in that build.
These pins do not change the licences or permit redistribution beyond their terms.

`omnigibson_6_1_0.kit` is the Isaac 6.1 experience from the original DCC port,
copied byte-for-byte (SHA256 `36d0df3b6fdee2c8a83a63a2ee0f6818f8ef4c1c272a0de32cdc5d3be74f0c79`).
It accompanies the OmniGibson compatibility patch. `check_sim_assets.py` checks
that the installed simulator version selects a readable experience and logo as
the agent UID; an import-only check does not cover these launch-time files.

Standalone `warp-lang` is pinned to 1.16.0 to match Isaac 6.1's bundled
`omni.warp.core`. Loading standalone 1.19 with the bundled 1.16 modules fails
during simulator initialization. The build check also verifies that these
versions agree before the image can be exported.

`solution/privileged/shapes.json` holds surface points sampled from the 21 YCB items above (1,000 to 2,300 points each),
used by the physical reference to choose grasp sections; it is derived from those models and carries their licence.
