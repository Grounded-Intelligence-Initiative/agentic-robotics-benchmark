# Native locomotion scoring design

The two tasks have equal weight. A straight run translates the pelvis along its initial heading toward a waypoint near five metres. An in-place right turn rotates the pelvis through a prescribed negative angle near 90 degrees about its initial position. The public practice commands are exactly 5 m and −90°. New independent 64-bit resets and command draws define each official panel. The reference and submissions receive the same public proprioception, remaining route and decoder history.

The primary metric is the number of successful physical stops divided by **all** scheduled starts. A success requires an upright robot, spatial containment, the requested signed heading, and continuous low planar speed and low absolute yaw rate at the goal. Distances and corridor deviations are in metres. Signed yaw is unwrapped from the actual reset attitude. Standing at reset fails the straight target. Turning left through the complementary angle fails the right target. A native fall, persistent route failure, timeout, or aborted solver earns zero. A physical terminal ends the episode at the first qualifying 2 ms native sample within the applied 20 ms row.

Development will establish the reference's reach and braking using separately identified practice seeds. The proposed stop envelope is a 0.25 m straight terminal disk, a 0.45 m straight lateral corridor, a 0.30 m turn terminal disk around its starting pivot with at most 0.45 m excursion, heading within 10°, planar speed ≤0.15 m/s and absolute yaw rate ≤0.25 rad/s for 0.75 s. These are development values. Final limits, held command strata and sample count are sealed before opening any hidden score. Left and right foot unload/reload events, detected with force hysteresis and a minimum transition dwell, describe stance changes.

Every executed native control row contains 64 FSQ scalar codes. Report row count, scalar-code count, adjacent-row coordinate changes / (64 × eligible adjacent-row pairs), simulated seconds, terminal position and heading errors, and RMS measured joint acceleration. For joint j use a[j,t]=(dq[j,t]−dq[j,t−5])/0.10 seconds at 50 Hz, with measured reset velocity at t=0. RMS is over all 29 joints and eligible samples, in rad/s². Report success-conditioned time alongside the total trial and failure counts. Physical durations and native-code counts do not use model text tokens or host compute latency.

The grader queries hidden same-tick control alternatives with identical wire semantics. A counterfactual goal can test command following; a rebased historical measurement from the same run can test dynamic feedback under the same original goal. Identical-input repeats estimate stochastic response changes. An input-blind replay and actual closed-loop references will be measured before fixing the gate.
