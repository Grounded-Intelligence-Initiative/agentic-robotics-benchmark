# Step 2: Install Actuator ID 3

> Route the actuator cable through part 600_03C, install actuator ID 3, and secure it with eight bolts.

- Section: Humanoid › Assemble the humanoid robot › Assemble › Left Leg Module › Thigh Assembly

## Parts needed

| Part | Count |
| - | -: |
| RJ-5378 actuator (part `600_02X`) (ID 3) with connected cables from Step 1 | 1 |
| `600_03C` | 1 |
| M4x10 Socket bolt | 8 |
| Threadlocker | As needed |

## Instructions

1. Place part `600_03C` flat on the surface such that the surface with an L shape groove is pointing upward toward the ceiling. The long hollow shaft should be facing toward you.

2. The hollow shaft contains a cable channel. Take the free connector of the double-ended XT30 (2+2) cable and route the cable through the channel to the other side.

3. Take the RJ-5378 actuator (ID 3) and align its port with the cable channel. Then slowly slide the actuator inside the hollow shaft until all the threaded holes on the actuator shell align with the holes on part `600_03C`.

4. Take **8 of** M4x10 Socket bolts and lightly tighten them into the holes on part `600_03C` to align with the actuator.

5. After the parts are aligned:

   > [!NOTE]
   >
   > **Not ready to apply threadlocker?**
   >
   > You can assemble without threadlocker while you check the fit, alignment, and orientation. When you are confident, disassemble as needed, apply threadlocker to the bolts, and reassemble them following these instructions.

   - remove **8 of** M4x10 Socket bolts one at a time in a star formation,
   - apply threadlocker,
   - then tighten them back to secure Part `600_03C` and the actuator together.
