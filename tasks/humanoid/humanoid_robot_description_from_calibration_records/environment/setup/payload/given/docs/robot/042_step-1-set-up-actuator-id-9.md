# Step 1: Set Up Actuator ID 9

> Connect the XT30 (2+2) cable connectors to actuator ID 9, route the 280 mm cable through the actuator shaft, and leave the 150 mm cable and its free connector accessible.

- Section: Humanoid › Assemble the humanoid robot › Assemble › Right Leg Module › Thigh Assembly

## Parts needed

| Part | Count |
| - | -: |
| RJ-5378 actuator (part `500_02X`) (ID 9) | 1 |
| 280 mm single-ended XT30 (2+2) cable | 1 |
| 150 mm double-ended XT30 (2+2) cable | 1 |

## Instructions

1. Place the RJ-5378 actuator (ID 9) on a flat surface with the shaft facing downward toward the floor.

2. Connect the connector of the 280 mm single-ended XT30 (2+2) cable to the actuator port nearest the center hole, then route the cable through the hollow shaft.

3. Connect one connector of the 150 mm double-ended XT30 (2+2) cable to the outer actuator port, leaving the cable and its free connector accessible.
