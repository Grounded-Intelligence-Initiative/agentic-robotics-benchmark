# Step 4: Prepare the Actuator Housing

> Install seven M4 square nuts in part 400_14C and retain them with three M4x16 Socket bolts and four M4x25 Socket bolts.

- Section: Humanoid › Assemble the humanoid robot › Assemble › Left Arm Module › Upper Arm Assembly

## Parts needed

| Part | Count |
| - | -: |
| `400_14C` | 1 |
| M4 square nuts | 7 |
| M4x16 Socket bolt | 3 |
| M4x25 Socket bolt | 4 |

## Instructions

1. Take part `400_14C`, put it on a flat surface with the inner hollow part facing upward

2. Put **3 of** M4 square nuts into the 3 slots on the surface of Part `400_14C`

3. Using **3 of** M4x16 Socket bolts and lightly tighten it on the circumference of Part `400_14C` where you have previously inserted the square nuts to secure the square nuts in place first. If you overtighten, the actuator will not fit in later on.

4. Put **4 of** M4 square nuts into the 4 slots on the round circumference of Part `400_14C`

5. Using **4 of** M4x25 Socket bolts and lightly tighten it on the circumference of Part `400_14C` where you have previously inserted the 4 square nuts to secure the square nuts in place first.
