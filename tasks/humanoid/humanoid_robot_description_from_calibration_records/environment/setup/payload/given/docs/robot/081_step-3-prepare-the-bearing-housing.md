# Step 3: Prepare the Bearing Housing

> Install three M4 square nuts, lightly tighten three M4x16 Socket bolts, and fit one flanged ball bearing in part 300_13C.

- Section: Humanoid › Assemble the humanoid robot › Assemble › Right Arm Module › Upper Arm Assembly

## Parts needed

| Part | Count |
| - | -: |
| `300_13C` | 1 |
| M4 square nuts | 3 |
| M4x16 Socket bolt | 3 |
| Flanged ball bearing FB-23 (part `300_19X`) | 1 |

## Instructions

1. Take part `300_13C` (the part with a side cable channel, not part `300_14C`) and place it on a flat surface with the inner hollow facing upward.

2. Place **3 of** M4 square nuts into the 3 slots on the surface of Part `300_13C`.

3. Using **3 of** M4x16 Socket bolts and lightly tighten it on the circumference of Part `300_13C` where you have previously inserted the square nuts to secure the square nuts in place first. If you over tighten, it will prevent the actuator from fitting in later on.

4. Place the flanged ball bearing FB-23 into the bearing hole on Part `300_13C`.
