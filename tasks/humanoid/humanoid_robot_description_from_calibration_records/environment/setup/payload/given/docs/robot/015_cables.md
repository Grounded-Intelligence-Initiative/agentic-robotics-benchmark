# Cables

> Identify and count every cable for the humanoid robot in one checklist.

- Section: Humanoid › Assemble the humanoid robot › Preparation › Module Checklists

Cables ship together in one labelled pack, so they are counted here in a single checklist instead of per module. Each row shows the total for the whole robot and what each cable connects.

Cables checklist: 19 required rows. Quantities are derived from the assembly instructions, not a shipping manifest. "Used in" links the assembly steps that use each item.
